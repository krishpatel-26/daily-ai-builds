# Hiring-focused portfolio builds

These three projects show different engineering strengths: customer-facing deployment workflows, revenue operations automation, and robotics telemetry diagnostics.

## 1. Customer Deployment OS — Day 011
Link: https://github.com/krishpatel-26/daily-ai-builds/tree/main/day-011/01-customer-deployment-os

A local-first workspace for customer signals, evidence capture, launch readiness gates, action planning, and customer handoff briefs. Built with HTML, CSS, and JavaScript.

## 2. Autonomous GTM Signal Engine — Day 012
Link: https://github.com/krishpatel-26/daily-ai-builds/tree/main/day-012/01-autonomous-gtm-signal-engine

A lead qualification workbench with transparent scoring, domain deduplication, suppression controls, editable outreach drafts, and CSV export. Built with HTML, CSS, and JavaScript.

## 3. Robotics Fleet Diagnostic Copilot — Day 013
Link: https://github.com/krishpatel-26/daily-ai-builds/tree/main/day-013/01-robotics-fleet-diagnostic-copilot

A telemetry analysis prototype that imports CSV sensor streams, flags timestamp gaps and potential numeric spikes, charts selected sensor traces, and exports diagnostic reports.

## Current maturity

These are prototypes, not production deployments. Each README documents scope and limitations. Manual test checklists are included, but browser QA and full test execution still need to be completed. Scoring and diagnostic outputs use explicit heuristics; no real customer or business outcomes are claimed.
