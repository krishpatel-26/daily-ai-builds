# Operations guide

1. Add or import current invoices.
2. Review overdue and due-soon metrics.
3. Sort by priority and verify each invoice against the actual accounting record.
4. Draft a reminder and review recipient, payment status, and wording.
5. Send manually using the user's normal email client.
6. Export CSV periodically to back up records.

If browser data is cleared, restore from an exported CSV. Do not rely on local storage as the only copy of important financial records.
