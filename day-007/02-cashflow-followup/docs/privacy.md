# Privacy and data handling

- Invoice records are stored in browser local storage.
- The app has no authentication and no server database.
- Import/export is user-initiated.
- Reminder text is generated locally and is not sent by the app.
- Demo records are synthetic examples and should not be mistaken for real invoices.
- Users should not share screenshots or exported CSVs containing confidential client information.
- Browser local storage is not encrypted storage. Anyone with access to the same browser profile may be able to inspect it.
- Export a backup before clearing browser data.
