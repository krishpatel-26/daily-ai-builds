# Release checklist

- [ ] Run `node --test tests/*.test.js`.
- [ ] Verify current Chrome, Firefox, and Safari.
- [ ] Test desktop and mobile widths.
- [ ] Check labels, focus states, and keyboard navigation.
- [ ] Test CSV commas, quotes, malformed headers, and duplicate invoice numbers.
- [ ] Add CSV formula-injection protection.
- [ ] Review browser console.
- [ ] Confirm local-only privacy statement matches behavior.
- [ ] Clearly label synthetic demo data.
- [ ] Capture a screenshot of the actual running app before launch.
- [ ] Avoid claims of payment verification or automatic email sending.
