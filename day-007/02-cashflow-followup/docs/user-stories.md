# User stories

- As a freelancer, I can add an invoice with client, amount, and due date so I have one place to review receivables.
- As an owner, I can see outstanding value and overdue count so I know what needs attention.
- As a busy operator, I can sort by priority and search clients so I can work the queue quickly.
- As a professional, I can draft a polite reminder so I do not have to start from a blank email.
- As a cautious user, I can review and send messages myself; the app never sends automatically.
- As a user switching devices, I can export/import CSV to move a backup.
- As a privacy-conscious user, I can use the app without an account or remote API.
- As a user, I can mark an invoice paid or reopen it if the status was entered incorrectly.
