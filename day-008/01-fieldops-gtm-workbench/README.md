# FieldOps GTM Workbench

A forward-deployed engineer's field toolkit: turn customer conversations and implementation blockers into structured evidence, prioritized actions, and measurable GTM follow-through.

## Problem
Customer-facing engineering teams often capture implementation details in call notes, tickets, CRM fields, and Slack. Product blockers and buying signals get lost between delivery and GTM.

## MVP
- Capture customer signals with source, severity, evidence, owner, and next action
- Score signals using an explainable rule set (not an opaque AI prediction)
- Convert validated signals into an implementation plan
- Generate account briefs and follow-up drafts for human review
- Track activation blockers and outcomes
- Export/import JSON for portability
- Local browser storage; no external API key or automatic outreach

## Run
Open `index.html` in a modern browser. No build step required.

## Status
Prototype. Data is local to the browser. The prioritization rules are heuristics, not validated predictions. Follow-up messages are drafts only. No CRM, email, ticketing, or production customer integration is included.
