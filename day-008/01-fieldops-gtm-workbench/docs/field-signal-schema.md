# Field signal data contract

Each signal includes a stable ID, account, type, severity, evidence, owner, next action, optional due date, stage, and created timestamp.

Types: blocker, adoption, opportunity, product, risk.
Severity: high, medium, low.
Stage: open, done.

Evidence should be a direct quote, reproducible observation, or traceable artifact summary. Avoid storing secrets, credentials, unnecessary personal data, or unsupported interpretations.
