# Acceptance criteria

- The user can identify the customer and target launch date.
- The user can mark each readiness check complete or incomplete.
- The readiness score is calculated from visible weights.
- Critical open items are highlighted separately from the overall score.
- The user can generate a plan with suggested owners and descriptions.
- The assessment can be exported as JSON.
- The plan can be downloaded as Markdown.
- The interface explains that scoring is heuristic and requires review.
- The app works without an API key or server.
