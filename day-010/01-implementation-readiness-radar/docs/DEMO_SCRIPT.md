# Demo walkthrough

1. Open the dashboard and explain that the default checklist is partially complete.
2. Point out the score, evidence coverage, and days to launch.
3. Explain why a critical integration or security item is highlighted.
4. Mark one technical prerequisite complete and observe the score update.
5. Generate a launch plan and review suggested owners.
6. Export JSON for a machine-readable snapshot or Markdown for a human-readable handoff.
7. Explain that the score is heuristic and the app does not validate evidence or approve a launch.
