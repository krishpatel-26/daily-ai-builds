# Implementation risk register

| Risk | Signal | Mitigation |
| --- | --- | --- |
| Access delay | Required permissions missing | Name customer IT owner and due date |
| Integration instability | End-to-end flow not tested | Run representative scenario and save evidence |
| Security delay | Review incomplete | Track reviewer, scope, and required artifacts |
| Poor data quality | Mapping or sample data fails | Agree validation rules and edge cases |
| Low adoption | Workflow unclear or training absent | Map user journey and schedule enablement |
| Launch rollback | Recovery path untested | Document rollback criteria and rehearse |
| Handoff gap | Support or GTM context missing | Share approved brief and escalation path |
