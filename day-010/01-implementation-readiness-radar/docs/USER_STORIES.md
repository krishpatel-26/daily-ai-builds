# User stories

- As an FDE, I want to identify technical dependencies before confirming a launch date.
- As an implementation lead, I want each blocker to have a proposed owner.
- As a GTM owner, I want to understand whether customer success criteria and handoff are complete.
- As a customer success manager, I want training and adoption risks visible alongside technical progress.
- As an engineering lead, I want security and acceptance gates surfaced even when the aggregate score looks healthy.
- As a reviewer, I want to export a plan without sending it automatically.
