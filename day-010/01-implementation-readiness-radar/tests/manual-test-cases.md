# Manual test cases

| Case | Action | Expected result |
| --- | --- | --- |
| Initial load | Open index.html | Dashboard renders with partial demo completion |
| Toggle item | Check or uncheck a box | Score and coverage update |
| Critical blocker | Leave security incomplete | Security appears among priority blockers |
| Complete all | Check every item | Score reaches 100 and open blockers disappear |
| Export | Click export assessment JSON | JSON file downloads |
| Plan | Generate launch plan | Ordered action plan appears |
| Download | Download Markdown | Plan file downloads |
| Reset | Click reset | All items unchecked and generated plan hidden |
| Mobile | Resize to narrow viewport | Layout stacks without horizontal overflow |
| Unknown date | Clear launch date | Days-to-launch shows a dash |
