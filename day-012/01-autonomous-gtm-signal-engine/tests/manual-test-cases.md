# Manual test checklist

- [ ] Load demo records and verify dashboard counts.
- [ ] Add a prospect with all required fields.
- [ ] Attempt to add an existing domain; confirm duplicate warning.
- [ ] Change search and filters; verify records update.
- [ ] Confirm score reasoning adds up according to the configured rules.
- [ ] Verify a suppressed record cannot produce an outreach draft.
- [ ] Generate an editable draft using only the entered record fields.
- [ ] Export CSV and verify headers and quoted values.
- [ ] Clear workspace and verify records are removed from browser storage.
- [ ] Test narrow viewport and keyboard operation.
- [ ] Confirm no email, CRM, or network request is initiated.
