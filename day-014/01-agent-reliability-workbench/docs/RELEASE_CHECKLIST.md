# Release checklist

- [ ] Run manual functional test cases.
- [ ] Run the app in supported browsers.
- [ ] Verify dataset import/export and malformed-input handling.
- [ ] Add automated tests for scoring and data validation before expanding.
- [ ] Confirm output status labels distinguish fail from review.
- [ ] Label illustrative metrics and synthetic traces.
- [ ] Inspect mobile layout and keyboard accessibility.
- [ ] Check exported traces for secrets and sensitive content.
- [ ] Record known limitations in README.
- [ ] Get review from an AI engineer or FDE before representing this as a validated tool.
