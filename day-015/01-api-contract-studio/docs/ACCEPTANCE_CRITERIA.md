# Acceptance criteria

- Built-in schema and payload load on launch.
- Valid sample passes supported rules.
- Invalid sample yields path-specific violations.
- Malformed JSON gives readable feedback.
- Schema and payload can be formatted.
- Old and current schemas can be compared.
- Positive and negative test payloads can be generated.
- Report and test packs download as JSON.
- No live API is called and limitations are visible.
