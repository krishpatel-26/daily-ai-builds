# Release checklist

- [ ] Compare sample behavior with a standards-compliant validator.
- [ ] Run manual test cases.
- [ ] Test malformed schema and payload JSON.
- [ ] Test nested properties and arrays.
- [ ] Review request and response compatibility assumptions.
- [ ] Verify export files parse as valid JSON.
- [ ] Check keyboard, focus, and mobile layout.
- [ ] Remove secrets and personal data from fixtures.
- [ ] Review limitations before sharing.
- [ ] Obtain API engineer feedback.
