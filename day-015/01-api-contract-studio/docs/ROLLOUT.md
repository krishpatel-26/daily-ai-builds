# Rollout plan

1. Review fixtures against a standards-compliant JSON Schema validator.
2. Add contract-specific tests for required fields, formats, boundaries, and nesting.
3. Use a full validator and compatibility checks in CI.
4. Document contract ownership, versioning, deprecation, and review policy.
5. Validate provider and consumer behavior in a staging environment before release.

This prototype is not a CI gate or substitute for an official validator.
