# Release checklist

- [ ] Run the manual tests on Windows 10 and Windows 11.
- [ ] Verify supported Electron and Tesseract.js versions.
- [ ] Test local translation models that are advertised.
- [ ] Test API failure paths and external-text disclosure.
- [ ] Check safeStorage behavior on standard Windows accounts.
- [ ] Verify tray actions, keyboard shortcuts and click-through.
- [ ] Review dependency audit output and Electron security guidance.
- [ ] Build and test the NSIS installer on a clean account.
- [ ] Update known limitations and version notes.
- [ ] Do not mark production-ready until runtime tests pass.
