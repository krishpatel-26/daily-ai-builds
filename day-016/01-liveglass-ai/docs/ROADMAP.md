# Roadmap

## MVP hardening
- Execute the full manual plan on Windows 10 and Windows 11.
- Correct any DPI and overlay coordinate mismatch.
- Check shortcuts, tray actions, click-through behavior and overlay capture protection.
- Improve actionable errors when OCR data or local translation models are missing.
- Add bounded diagnostic logs and endpoint health checks.

## Next
- User-selectable region and multi-monitor mode.
- Detect changed regions and cache translations.
- Segment-safe API translation and language auto-detection.
- Better text replacement, background masking, font controls and accessibility.
- Signed installer, update mechanism and release automation.
