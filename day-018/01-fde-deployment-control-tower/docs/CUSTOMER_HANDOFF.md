# Customer handoff format

The exported Markdown handoff includes:
- customer, integration, environment, FDE owner, target date and success criteria
- readiness score and recommendation state
- completed/failed checks and evidence gaps
- all eight gates and the evidence notes recorded against each check
- open blockers with severity, owner and due date
- recent decisions and customer updates
- recommended next steps generated from incomplete checks and open blockers

## Before sharing
Review the file manually. Confirm names, timezones, ticket links, endpoint metadata and all evidence are appropriate for the recipient. The report masks common secret patterns but is not a certified redaction tool. A go-to-review recommendation is not final launch authorization.
