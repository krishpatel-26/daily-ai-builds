# Privacy and data handling

- The comparison and validation run in the browser.
- The included Node server serves static files on loopback only; no diagnostic backend receives contract text or payloads.
- There are no analytics requests or customer API calls.
- Editors contain the user's full text until the user clears them or closes the page.
- Exported reports and JSON may contain contract examples or descriptions; review them before sharing.
- Do not paste real credentials, production PII or private customer payloads into a public demo or commit them to the repository.

Local processing is not the same as encrypted storage. Browser extensions, shared machines, browser profiles and exported files remain part of the data boundary.
