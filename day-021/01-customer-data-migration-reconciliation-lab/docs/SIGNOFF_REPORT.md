# Migration sign-off report

The exported Markdown report records:
- run timestamp and project/reviewer details
- source and target row/column counts
- selected keys and mapped fields
- normalization options
- matched record count and coverage
- missing and target-only records
- duplicate key groups and blank-key rows
- mapped field mismatches and recommended actions
- reviewer decision notes
- explicit scope limitations

Review the report and exception list before sharing. A RECONCILED status means no differences were found in the configured comparison scope, not that every business requirement or migration control has been verified.
