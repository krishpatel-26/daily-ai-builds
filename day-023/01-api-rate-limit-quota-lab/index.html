Things the simulator makes visible

  • Fixed window: simple counters can allow a burst at the boundary.
  • Sliding window: smooths boundary behavior but needs request history or approximation.
  • Token bucket: permits a controlled burst while replenishing capacity over time.
  • Distributed systems: this local simulation does not provide atomic cross-instance enforcement.
