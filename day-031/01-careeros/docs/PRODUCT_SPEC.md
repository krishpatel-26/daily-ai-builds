# CareerOS Product Specification

## User problem
Early-career candidates have fragmented evidence of capability, unclear role requirements, and no execution loop connecting skill development to applications.

## Product promise
Turn a target role into a transparent, editable plan: evidence → gaps → practice → portfolio proof → application tracking.

## Core journey
1. Enter target role and resume evidence.
2. Inspect extracted skills and evidence snippets.
3. Review weighted skill gaps.
4. Generate a learning roadmap.
5. Select portfolio projects mapped to missing skills.
6. Track applications and follow-up dates.
7. Re-run analysis as evidence changes.

## Non-goals
CareerOS does not predict hiring outcomes, rank people for employers, automatically submit applications, invent qualifications, or replace professional career advice.

## Success metrics
Profile activation, roadmap milestones completed, inferred skills reviewed by user, portfolio deliverables completed, and applications tracked.
