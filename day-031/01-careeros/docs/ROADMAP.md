# Engineering Roadmap

## Phase 1 — local prototype
Profile, heuristic skill extraction, role matching, roadmap, portfolio recommendations, and application tracker.

## Phase 2 — evidence quality
PDF/DOCX parsing, source spans, synonym ontology, user verification, calibrated extraction evaluation.

## Phase 3 — intelligence
Labor-market data connectors, semantic role matching, skill graph, assessment generation, and LLM-assisted coaching.

## Phase 4 — production
Authentication, tenant isolation, encrypted storage, audit logging, observability, backups, accessibility audit, and deployment automation.

## Phase 5 — outcome research
Opt-in longitudinal study of learning completion, portfolio evidence, and application outcomes with privacy safeguards.
