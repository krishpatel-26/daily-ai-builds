# Safety and Decision-Support Boundaries

FleetPulse is an engineering prototype. It is not certified, validated, or intended for autonomous control or safety-critical maintenance dispatch.

- Health index is a heuristic, not probability of failure.
- Anomaly flags require sensor and operating-context review.
- Thresholds must be calibrated per asset and operating regime.
- Sensor faults, maintenance events, process changes and load variations can create false positives.
- Qualified personnel must assess and authorize maintenance actions.
- Never connect this prototype directly to a PLC, safety controller, or actuation path.
