# SocialSim — Relationship-Driven AI World Simulator
Day 036. Deterministic prototype modelling directed trust, fear, loyalty and rivalry; social actions; bounded rumour propagation; and explainable emergent events.
Run: Python 3.10+, pip install -r requirements.txt, uvicorn app.main:app --reload. Open http://127.0.0.1:8000 and /docs.
Synthetic fictional world and authored rules; no live LLM or production multiplayer backend.
