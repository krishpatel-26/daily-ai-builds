# CausalWorld — Counterfactual Intelligence Engine
Day 037. A deterministic structural causal model for asking what-if questions in a fictional game world.
Features: validated DAG, direct interventions, topological propagation, baseline/counterfactual comparison, impact ranking, causal path explanations, FastAPI and browser workbench.
Run: Python 3.10+, pip install -r requirements.txt, uvicorn app.main:app --reload. Visit http://127.0.0.1:8000 and /docs.
Boundary: authored equations and synthetic data; not a learned causal model, probability forecast or proof of real-world causation.
