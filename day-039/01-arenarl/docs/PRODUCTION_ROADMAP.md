# Production Roadmap
1. Add multiple map layouts and randomized spawn/resource placements.
2. Run multi-seed tournaments with confidence intervals.
3. Add self-play and population-based policy evaluation.
4. Explore centralized training with decentralized execution.

6. Integrate PyTorch-based deep Q networks only after a benchmark suite exists.
