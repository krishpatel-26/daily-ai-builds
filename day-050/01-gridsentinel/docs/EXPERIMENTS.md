# Experiment plan

1. Enumerate each N−1 outage and compute islanding/served load.
2. Compare no upgrade, backup at critical buses, reinforced selected corridors and combined strategy.
3. Record line overloads separately from unserved demand.
4. Vary load, generator availability and reactance assumptions.
5. Compare against a validated load-flow library for the same network, preferably through an independently derived AC solution.
6. Report uncertainty, sensitivity and limits without predicting real outages.
