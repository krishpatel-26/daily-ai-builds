# Data dictionary

Supplier: capacity_per_day, lead_days, unit_cost. Warehouse: opening_stock. Outlet: warehouse, average demand, opening stock, priority. On-hand inventory: currently available units. Pipeline: scheduled future deliveries. Inventory position: on-hand + inbound orders. Fill rate: sold/demand. Lost sales: demand not fulfilled immediately. Costs: fictional procurement, transport, holding and lost-sales penalties.
