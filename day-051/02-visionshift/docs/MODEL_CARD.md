# Model card — synthetic logistic inspection classifier
**Intended use:** educational testing of model drift and active learning. **Training:** four normalized synthetic numeric features with a stochastic binary oracle. **Algorithm:** logistic regression optimized via full-batch gradient descent. **Limitations:** not a computer-vision model, not a CNN, no image feature extraction, no deployed quality assurance, and no real manufacturing accuracy. **Risks:** mistaken translation of synthetic accuracy or PSI into field claims. **Required evaluation:** calibrated visual datasets with independent labeling, shift-aware holdouts, uncertainty/false-negative analysis, and operational expert review.
