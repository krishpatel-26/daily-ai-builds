# Privacy and data handling

- Contract JSON is pasted or selected locally in the browser.
- The prototype does not send contract contents to an API or third-party service.
- Sample registry and fixture names are fictional.
- The UI rejects individual files above 2 MB.
- Browser extensions and local machine access remain outside this app's security boundary.
- Exports may reveal internal route names and schema structure. Review them before sharing externally.
- Do not include real secrets, bearer tokens, customer personal data, or production payloads in a public demonstration.
