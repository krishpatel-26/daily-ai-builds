# Benchmark protocol
Use paired synthetic test seeds across all eight candidate roots. At each trial, inject a persistent cascading signal and a single brief unrelated decoy spike. Compare root top-1 accuracy for topology/time template matching against the service with the largest observed peak. Report trial count and uniform-chance reference. Note that the decoy is explicitly designed to make peak-only ranking weak, and the inference algorithm has access to the generator's topology and temporal kernel. Real incident evaluation requires unknown-topology tests, metric dropout, correlated dependencies, feedback loops and independent incidents.
