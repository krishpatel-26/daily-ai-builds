# Benchmark protocol

Compare six scenarios: each of three aggregation methods with attacks off/on. For the reported multi-seed benchmark, use seeds 11, 22, 33, 44, 55, 18 communication rounds, nine clients, two malicious clients and a held-out synthetic test set of 700 samples per seed. The adversarial update is negative five times each malicious client's local delta.

Report mean, minimum and maximum held-out accuracy. Do not report downstream generalization, differential privacy, real network costs, or real security effectiveness. Median and trimmed mean need independent evaluation under more sophisticated adaptive attacks, non-IID client populations and variable sample sizes.
