# Hypothetical impulses

A candidate scalar impulse modifies the initial velocity along its existing direction by up to ±2 meters per second. Each alternative is separately propagated. Ranking favors the largest minimum separation across objects minus a small impulse penalty. This omits timing optimization, higher-fidelity perturbations, orbital constraints, uncertain states, mission objectives, and operator approvals. It is only a simulation what-if, not guidance to execute a maneuver.
